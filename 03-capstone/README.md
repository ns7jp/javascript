# 第3部: 総合ミニプロジェクト

第1部([01-basics](../01-basics/README.md))で学んだJavaScriptの基礎と、第2部([02-server-engineer-practice](../02-server-engineer-practice/README.md))で学んだサーバー構築エンジニア実践のスキルを組み合わせ、一つのまとまったツールとして完成させる総合演習パートです。個々の章で学んだ知識を組み合わせて実際に動くものを作り切ることで、実務に近い開発の流れ(設計・実装・テスト・ログ出力まで)を体験することを目的としています。

このパートでは「システムヘルスチェッカー」を実装しています。設定ファイルに定義した複数のサービスに対して死活監視を行い、その結果をログファイルに記録するツールです。詳細な仕様・使い方・実装内容については [system-health-checker/README.md](./system-health-checker/README.md) を参照してください。
