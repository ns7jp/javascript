# 採用担当者・面接官の方へ

このリポジトリをご覧いただきありがとうございます。プログラミング未経験からサーバー構築エンジニア(インフラエンジニア)への転職を目指し、JavaScript / Node.js の基礎学習に取り組んだ記録です。以下のような点を通じて、実務につながる基礎力と実行力をお伝えできればと考えています。

## このリポジトリで示そうとしていること

- **JavaScript / Node.jsの基礎を体系的に理解していること**: 変数・型・制御構文といった基礎文法から、非同期処理・クラス・JSON操作まで、13章にわたって段階的に学習しています([01-basics](../01-basics/README.md))。
- **自動テストを書く習慣**: 各章に演習と対になる自動テスト(`solution.test.js`)を用意し、`node --test` を使ってコードの正しさを検証する習慣を身につけています。
- **CI/CDパイプラインの基本**: GitHub Actions(`.github/workflows/test.yml`)を用いて、プッシュ・プルリクエストのたびに複数のNode.jsバージョンで自動テストが実行される仕組みを構築しています。
- **実務を意識したミニプロジェクトを完成させる実行力**: 文法学習だけで終わらせず、Node.jsのコアモジュールを使ったCLIツール作成、簡易HTTPサーバー構築、ログ解析、設定ファイル・環境変数の管理といった、サーバー構築エンジニアの業務に近いテーマに取り組んでいます([02-server-engineer-practice](../02-server-engineer-practice/README.md))。

## 特に見ていただきたい箇所

まずは総合ミニプロジェクトの **[03-capstone/system-health-checker](../03-capstone/system-health-checker/README.md)** をご覧ください。設定ファイル(`services.config.json`)に基づいて複数のサービスの死活監視を行い、結果をログとして記録するツールで、これまでの学習内容を統合した成果物です。テストコードやディレクトリ構成も含めて、実装の全体像を確認いただけます。

その上で、基礎力の裏付けとして [01-basics](../01-basics/README.md) や [02-server-engineer-practice](../02-server-engineer-practice/README.md) の各章もあわせてご参照いただければ幸いです。
