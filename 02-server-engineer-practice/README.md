# 第2部: サーバー構築エンジニア実践編

第1部で学んだJavaScriptの基礎を土台に、サーバー構築エンジニア(インフラエンジニア)の実務を強く意識した題材に取り組むパートです。Node.jsのコアモジュールを使ったCLIツールや簡易HTTPサーバーの構築、ログ解析、設定ファイル・環境変数の管理など、現場でそのまま応用できるスキルの習得を目指します。
