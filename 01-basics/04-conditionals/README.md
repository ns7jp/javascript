# 条件分岐

## この章で学ぶこと

- `if` / `else if` / `else` を使って「条件によって処理を分ける」書き方
- `switch` 文を使って「1つの値のパターン分け」を見やすく書く方法
- 三項演算子(`条件 ? 値1 : 值2`)を使った短い条件分岐の書き方
- 真偽値ではない値が `if` の条件式に渡ったときに、`true`/`false` のどちらとして扱われるか(truthy/falsy)

## 解説

### `if` / `else if` / `else`

サーバー構築の現場では、「アクセスしてきたユーザーの権限によって処理を変える」「サーバーの負荷が一定を超えたら警告を出す」など、条件によって処理を分岐させる場面が非常に多くあります。JavaScript では `if` 文を使ってこれを実現します。

```javascript
const score = 75;

if (score >= 90) {
  console.log("優");
} else if (score >= 70) {
  console.log("良");
} else if (score >= 50) {
  console.log("可");
} else {
  console.log("不可");
}
```

ポイントは、**上から順番に条件を確認していき、最初に条件が `true` になったブロックだけが実行される**という点です。`score = 75` の場合、`score >= 90` は `false` なのでスキップされ、次の `score >= 70` が `true` になった時点でそのブロックが実行され、以降の `else if` や `else` は評価すらされません(条件は上から順に、しかも一つでも合致したら残りは確認されないことに注意してください)。

条件の順番を間違えると、意図しない結果になることがあります。例えば先ほどの例で `score >= 50` を一番上に書いてしまうと、`score = 95` の人まで「可」と判定されてしまいます。**範囲を判定する `if` 文は、条件の順番(範囲が狭いものを先に、広いものを後に、あるいはその逆)がとても重要です。**

### `switch` 文

「1つの値が、いくつかの決まったパターンのどれに当てはまるか」を判定したいときは、`switch` 文を使うと `if / else if` の連続よりも見やすく書けることがあります。

```javascript
const dayNumber = 3;
let dayName;

switch (dayNumber) {
  case 0:
    dayName = "日曜日";
    break;
  case 1:
    dayName = "月曜日";
    break;
  case 2:
    dayName = "火曜日";
    break;
  case 3:
    dayName = "水曜日";
    break;
  default:
    dayName = "不明な曜日番号";
}

console.log(dayName); // "水曜日"
```

`switch` 文でとても重要なのが `break` です。`break` は「ここで `switch` 文から抜ける」という命令で、これを書き忘れると、該当した `case` の処理を実行した後に**そのまま次の `case` の処理まで実行され続けてしまいます**(これを「フォールスルー」と呼びます)。

```javascript
switch (2) {
  case 1:
    console.log("1です");
  case 2:
    console.log("2です"); // ここが実行される
  case 3:
    console.log("3です"); // breakがないので、これも実行されてしまう!
    break;
  default:
    console.log("不明です");
}
// 出力: "2です" と "3です" の両方が表示される
```

どの `case` にも当てはまらなかった場合の処理は `default` に書きます(`if` 文の `else` にあたるものです)。

### 三項演算子

条件によって「返す値」を1行で切り替えたいときは、三項演算子(`条件 ? 真の場合の値 : 偽の場合の値`)が便利です。

```javascript
const age = 20;
const message = age >= 20 ? "成人です" : "未成年です";
console.log(message); // "成人です"
```

これは次の `if` 文と全く同じ意味です。

```javascript
let message;
if (age >= 20) {
  message = "成人です";
} else {
  message = "未成年です";
}
```

三項演算子は短く書けて便利ですが、条件を入れ子(ネスト)にしすぎると一気に読みにくくなるので注意が必要です。「単純な二択」のときだけ使うのがおすすめです。

### truthy(真っぽい値)と falsy(偽っぽい値)

JavaScript の `if` 文の条件式には、`true`/`false` 以外の値を書くこともできます。その場合、JavaScript は値を自動的に真偽値へと変換して判定します。この性質のことを「truthy(トゥルーシー、真として扱われる)」「falsy(フォルシー、偽として扱われる)」と呼びます。

**falsy と判定される値は、次の7種類しかありません(これ以外は全て truthy です)。**

```javascript
false
0
-0
0n      // BigIntの0
""      // 空文字列
null
undefined
NaN
```

```javascript
if ("") {
  console.log("実行されない"); // 空文字列はfalsyなので実行されない
}

if ("0") {
  console.log("実行される"); // "0"は「文字列」であり空文字列ではないのでtruthy!
}

if ([]) {
  console.log("実行される"); // 空配列もtruthy(意外なので要注意)
}
```

特に `"0"`(文字列としての0)や `[]`(空配列)、`{}`(空オブジェクト)は、直感的には「空っぽ」で falsy に見えるかもしれませんが、実際は truthy 扱いになります。サーバーサイドの処理では、APIから受け取ったデータが「空文字列なのか」「文字列の"0"なのか」を混同すると、意図しない分岐に入ってしまうことがあるため注意しましょう。

## つまずきやすいポイント

- **`switch` 文で `break` を書き忘れる**: `break` がないと、該当した `case` 以降の処理が意図せず全部実行されてしまいます(フォールスルー)。1つの `case` を書いたら、必ず `break` があるか確認する癖をつけましょう。
- **`if / else if` の条件の順番を間違える**: 範囲を判定する条件は、順番によって結果が変わります。例えば点数の判定で、広い範囲の条件を先に書いてしまうと、狭い範囲の条件が一生評価されなくなります。
- **`"0"`(文字列)や `[]`(空配列)を falsy だと勘違いする**: falsy になるのは `false, 0, -0, 0n, "", null, undefined, NaN` の7種類だけです。それ以外(空配列や空オブジェクトを含む)は全て truthy です。
- **三項演算子をネスト(入れ子)しすぎて読めなくなる**: `a ? b ? 1 : 2 : 3` のような書き方は、パッと見て意味を理解するのが難しくなります。3択以上になりそうな場合は `if / else if` や `switch` を使いましょう。

## 演習問題

`exercise.js` に、次の2つの関数を実装してください。

### 1. `classifyScore(score)`

- 引数: `score`(0〜100の数値を想定)
- 戻り値: 点数に応じた評価を表す文字列
  - `score >= 90` → `"優"`
  - `score >= 70` → `"良"`
  - `score >= 50` → `"可"`
  - それ以外(50未満)→ `"不可"`
- **`if / else if / else` を使って実装してください。**
- 例:
  - `classifyScore(95)` → `"優"`
  - `classifyScore(70)` → `"良"`(境界値ちょうどは含まれる)
  - `classifyScore(50)` → `"可"`
  - `classifyScore(30)` → `"不可"`

### 2. `judgeWithSwitch(dayNumber)`

- 引数: `dayNumber`(0〜6の整数。0=日曜日, 1=月曜日, ... 6=土曜日 とする)
- 戻り値: 曜日を表す日本語の文字列(`"日曜日"` `"月曜日"` `"火曜日"` `"水曜日"` `"木曜日"` `"金曜日"` `"土曜日"`)
- 0〜6のどれにも当てはまらない値が渡された場合は `"不正な曜日番号です"` を返す
- **`switch` 文を使って実装してください。**
- 例:
  - `judgeWithSwitch(0)` → `"日曜日"`
  - `judgeWithSwitch(6)` → `"土曜日"`
  - `judgeWithSwitch(7)` → `"不正な曜日番号です"`
