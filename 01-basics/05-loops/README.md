# 繰り返し処理

## この章で学ぶこと

- `for` 文を使って「決まった回数だけ処理を繰り返す」書き方
- `while` 文と `do-while` 文を使って「条件を満たす間だけ処理を繰り返す」書き方
- `for...of` 文を使って配列の要素を順番に取り出す方法
- `for...in` 文を使ってオブジェクトのプロパティ名を順番に取り出す方法
- `break`(繰り返しの中断)と `continue`(その回だけスキップ)の使い分け

## 解説

### `for` 文

サーバー構築の現場では、「ログファイルを1行ずつ処理する」「決まった回数だけリトライ(再試行)する」など、同じ処理を繰り返し実行する場面が非常に多くあります。JavaScript で最も基本的な繰り返し処理が `for` 文です。

```javascript
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
// 出力: 1 2 3 4 5 が順番に表示される
```

`for` 文は `for (初期化; 継続条件; 更新式)` という3つの部分で構成されています。

- **初期化**: 最初に一度だけ実行される(例: `let i = 1` でカウンター変数を作る)
- **継続条件**: 毎回のループの最初に確認され、`true` の間だけ処理が続く(例: `i <= 5`)
- **更新式**: 1回のループが終わるたびに実行される(例: `i++` で `i` を1増やす)

この仕組みを使うと、「1からnまでの合計を求める」処理は次のように書けます。

```javascript
function sumUpTo(n) {
  let total = 0;
  for (let i = 1; i <= n; i++) {
    total += i; // total = total + i と同じ意味
  }
  return total;
}

sumUpTo(5); // 1+2+3+4+5 = 15
```

### `while` 文

「繰り返す回数があらかじめ決まっていないが、ある条件を満たす間は繰り返したい」というときは `while` 文を使います。

```javascript
let count = 0;
while (count < 3) {
  console.log(count);
  count++;
}
// 出力: 0 1 2
```

`while` 文は継続条件だけを書きます。**注意しなければならないのは、ループの中で条件がいつか `false` になるように変数を更新し忘れると、無限ループ(いつまでも終わらない繰り返し)になってしまう**ということです。サーバーのプログラムで無限ループが発生すると、CPU(処理装置)を使い切ってサーバーが応答しなくなる、といった深刻な問題につながります。

### `do-while` 文

`do-while` 文は `while` 文とよく似ていますが、**条件を確認する前に、必ず1回は処理を実行する**という違いがあります。

```javascript
let n = 10;
do {
  console.log(n); // 条件がfalseでも1回は必ず実行される
  n++;
} while (n < 5);
// 出力: 10 (条件 n < 5 は最初からfalseだが、1回は実行される)
```

「メニューを表示して、ユーザーが終了を選ぶまで繰り返す」のように、「最低1回は必ず実行したい」処理があるときに向いています。

### `for...of` 文

配列の中身を1つずつ順番に取り出したいときは `for...of` 文が便利です。

```javascript
const fruits = ["りんご", "みかん", "ぶどう"];
for (const fruit of fruits) {
  console.log(fruit);
}
// 出力: りんご みかん ぶどう
```

`for` 文のように `i` というインデックス(添字、配列の中での位置番号)を自分で管理する必要がなく、要素そのものを直接扱えるのが特徴です。

### `for...in` 文

オブジェクトのプロパティ名(キー)を順番に取り出したいときは `for...in` 文を使います。

```javascript
const user = { name: "たかし", age: 25 };
for (const key in user) {
  console.log(key, user[key]);
}
// 出力: name たかし / age 25
```

**`for...of` と `for...in` は名前が似ていて混同しやすいですが、役割が全く異なります。** `for...of` は配列などの「値」を1つずつ取り出すのに対し、`for...in` はオブジェクトの「プロパティ名(キー)」を取り出します。配列に `for...in` を使うこともできますが、キーが文字列の `"0"` `"1"` `"2"` ... として取り出されてしまい、意図しない挙動になりやすいため、**配列を順番に処理したいときは基本的に `for...of` を使う**ようにしましょう。

### `break` と `continue`

`break` と `continue` は、繰り返し処理の流れを途中で変えるための命令です。

- **`break`**: その時点で繰り返し処理**全体を終了**する
- **`continue`**: **その回の処理だけ**をスキップして、次の回に進む

```javascript
for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    break; // iが5になったら、繰り返し自体をやめる
  }
  console.log(i);
}
// 出力: 1 2 3 4 (5になった時点でループ全体が終わる)
```

```javascript
for (let i = 1; i <= 5; i++) {
  if (i % 2 === 0) {
    continue; // 偶数のときはこの回の処理をスキップして次へ
  }
  console.log(i);
}
// 出力: 1 3 5 (偶数だけスキップされ、ループ自体は続く)
```

`continue` を使うと、「配列の中から条件に合うものだけを集める」といった処理を、読みやすく書くことができます。

```javascript
function collectEvenNumbers(numbers) {
  const result = [];
  for (const num of numbers) {
    if (num % 2 !== 0) {
      continue; // 奇数はスキップして、結果に含めない
    }
    result.push(num);
  }
  return result;
}

collectEvenNumbers([1, 2, 3, 4, 5, 6]); // [2, 4, 6]
```

## つまずきやすいポイント

- **`while` 文で無限ループを作ってしまう**: ループの中で継続条件に関わる変数を更新し忘れると、`while (true)` と同じ状態になってしまいます。`while` を書いたら、必ず「条件がいつか `false` になるか」を確認する癖をつけましょう。
- **`for...of` と `for...in` を混同する**: `for...of` は「値」を、`for...in` は「キー(プロパティ名)」を取り出します。配列に `for...in` を使うと、要素そのものではなく `"0"` のような文字列のインデックスが取れてしまい、意図しない結果になりがちです。
- **`break` と `continue` の違いを取り違える**: `break` は繰り返し処理そのものを終了させますが、`continue` はその回だけをスキップして繰り返し自体は続きます。「途中で完全にやめたいのか」「その回だけ無視したいのか」を意識して使い分けましょう。
- **`for` 文の継続条件の境界値を間違える**: `i <= n` と書くべきところを `i < n` と書いてしまうと、最後の1回が実行されなかったり(境界値のズレ)、逆に1回多く実行されたりします。「n回繰り返したいのか」「n未満の間だけ繰り返したいのか」を書く前に整理しましょう。

## 演習問題

`exercise.js` に、次の2つの関数を実装してください。

### 1. `sumUpTo(n)`

- 引数: `n`(整数)
- 戻り値: `1` から `n` までの整数の合計
  - `n` が `1` 未満(`0` 以下)の場合は、合計する数が存在しないため `0` を返す
- **`for` 文を使って実装してください。**
- 例:
  - `sumUpTo(5)` → `15`(1+2+3+4+5)
  - `sumUpTo(1)` → `1`(境界値。1つだけの合計)
  - `sumUpTo(0)` → `0`
  - `sumUpTo(-3)` → `0`

### 2. `collectEvenNumbers(numbers)`

- 引数: `numbers`(数値の配列)
- 戻り値: `numbers` の中から偶数だけを取り出した新しい配列(元の並び順を保つ)
- **`for...of` と `continue` を使って実装してください。**
- 例:
  - `collectEvenNumbers([1, 2, 3, 4, 5, 6])` → `[2, 4, 6]`
  - `collectEvenNumbers([1, 3, 5])` → `[]`(偶数が1つもない)
  - `collectEvenNumbers([])` → `[]`(空配列を渡した場合)
  - `collectEvenNumbers([-4, -3, -2])` → `[-4, -2]`(負の偶数も対象)
